# Clean Glass
Tired of noisy spots and ugly streaks on Minecraft glass? **Clean Glass** is a lightweight, vanilla-friendly resource pack that removes distracting pixel noise from all glass textures while keeping the original vanilla art style.

Perfect for builders, this pack delivers crystal-clear windows without changing the overall look and feel of Minecraft. No extra mods or OptiFine required — just install and enjoy clean, unobstructed views.

## ✨ Features
- Cleans textures for glass blocks, glass panes, stained glass and tinted glass
- Preserves vanilla style, no drastic visual changes
- Lightweight, no performance impact
- Works with most shader packs and other resource packs

## 📋 Notes
This pack only edits glass-related textures. It does **not** add connected glass. If you want connected glass, use the Continuity mod separately.
